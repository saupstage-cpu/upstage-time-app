# Admin guide

## Main areas

- Dashboard: live status and daily counts
- Attendance: photo/time/location/job review and approvals
- Jobs: create and maintain projects
- Reports: export CSV/PDF for payroll or review
- Xero: stage approved timesheets for payroll sync
- Settings: geofence, break rules, retention
- Audit log: every important change

## Weekly flow

1. review submitted attendance
2. correct exceptions where authorized
3. approve/reject timesheets
4. export reports or send approved totals to Xero
5. review audit trail and sync history
