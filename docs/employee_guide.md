# Employee guide

## Daily flow

1. log in
2. select current job
3. tap Time In
4. take live selfie
5. allow location capture
6. work and add work logs if needed
7. start and end breaks using the dedicated buttons
8. tap Time Out
9. take final selfie and optionally add work summary
10. submit weekly timesheet

## Rules

- approved records cannot be edited by employees
- gallery upload for Time In / Time Out is disabled by default
- location is captured only during attendance events unless extra site tracking is enabled by the company
